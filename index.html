MOBILE GUIDE

How to download your Canvas .ics on iPhone & Android

  1. Open Canvas in your phone's browser: Open Safari (iPhone) or Chrome (Android), log in to Canvas, and tap Calendar.
  2. Find Calendar Feed: Scroll to the bottom and tap Calendar Feed.
    💡 Tip: If not visible on mobile, request desktop site: Safari tap aA → Desktop Website; Chrome tap ⋮ → Desktop site.
  3. Download .ics file or copy link:
    • iPhone (Safari): Tap feed link → tap Download or Share → Save to Files.
    • Android (Chrome): Tap feed link to save .ics to Downloads.
    • Or tap and hold link to Copy Link.
  4. Import into Daymark:
    • Tap ↑ Import .ics file to select the downloaded file, OR
    • Tap 📋 Paste .ics link to paste the link or calendar text!
