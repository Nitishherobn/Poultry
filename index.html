Canvas assignments

Checking connection…

Do this on your phone. The Canvas Student app may not show the private Calendar Feed link, so use your phone's browser for these steps.

  1. Open Safari on iPhone or Chrome on Android, sign in to your school's Canvas site, and open Calendar.
  2. If the feed option is missing, request the desktop site: in iPhone Safari tap aA → Request Desktop Website; in Android Chrome tap ⋮ → Desktop site.
  3. Tap Calendar Feed. If Canvas opens the feed, save/download the .ics file: use Share → Save to Files on iPhone or Download on Android.
  4. Return to Daymark and open Schedule → Import Canvas .ics. Pick the file from Files or Downloads. The calendar is parsed on your phone.

This phone preview does not send private feed URLs over Wi-Fi. Go to Schedule to import your downloaded .ics file →
